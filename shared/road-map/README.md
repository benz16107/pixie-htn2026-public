# Toronto scene map cache

Nine unmodified OpenStreetMap raster tiles at zoom 15, downloaded September 20, 2026. Tile origin and zoom are in `index.json`; filenames use row-column positions in a 3 × 3 grid.

Source: `https://tile.openstreetmap.org/15/{x}/{y}.png`.

© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Both renderers display attribution. The cache covers the Toronto example intersection. Web locations outside the cached extent show coordinates and an explicit map gap. The map does not establish where any evidence was recorded.
