# Road help screenshots

Captured from the working Expo web app and Intact website on September 20, 2026. Mobile views use a 390 × 844 viewport. These are browser captures, not physical iPhone captures.

- [Driver incident record](driver.png) shows the shared report, scene location, and incoming perspectives.
- [Witness contribution balance](contributions.png) shows the demo credit after insurer acceptance.
- [Insurer evidence workspace](insurer.png) shows the same incident, both files, reviewer notes, and export.

All scene material in these captures is explicitly illustrated test data. The flow used two separate browser contexts and real file uploads. File hashes, status updates, credit bookkeeping, and ZIP exports ran through the shared API. Credits have no cash value, and the images do not depict an actual collision.
