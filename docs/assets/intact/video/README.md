# Intact video source footage

`mcp-inspector.webm` is a silent browser recording captured from the working Intact website on September 20, 2026. It shows a tenant estimate with $50,000 contents and then the bundled vehicle comparison. Both actions call the running MCP server. The page selects preset tools; this recording does not show an autonomous AI conversation.

Capture size: 1440 × 900. This is source footage for the three-minute edit, not a finished submission video. No captions, narration, music, or timing edits have been added.

The chapter script and device shot list are in `DEMO/11-INTACT-VIDEO.md`. Record the real iPhone Home Screen widget and Lock Screen Live Activity separately using the now-verified development build. The current machine has no iOS Simulator.
