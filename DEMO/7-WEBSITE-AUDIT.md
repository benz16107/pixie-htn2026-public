# Current website audit

The website presents two products instead of one crowded navigation system. Federato contains the commercial queue, case analysis, live desk, guideline, portfolio map, Ask, and backtest. Intact contains one focused Home or Auto lifecycle presentation across Quote, Decide, Protect, and Recover.

The Federato queue defaults to the case that needs judgment. Case 138 keeps the strongest explanation tools: provenance, score interval, waterfall, what-if, sensitivity, precedent, memory, and bounded override. The 3D portfolio map provides the main visual proof after the case.

The Intact page behaves like a presentation. Each stage pairs one claim with one proof and one action. The working consumer experience lives in Expo. Home pricing is tenant-only. Auto rates and vehicle listings are synthetic. Recover uses Pixie's first-party Safety, Record, and Plan flow for both routes, with a local PDF the customer can save or share.

The Expo app matches the Intact visual system and keeps the lifecycle visible through four tabs. The native development build adds SwiftUI and Jetpack Compose controls, plus an iOS widget and Live Activity. Expo Go and web use a labelled fallback.
